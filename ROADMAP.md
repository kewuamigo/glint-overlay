# Roadmap

This is a living outline of where Glint is headed. Dates are intentional soft; priority can shift with community feedback.

## Near term

- **Solid open-source baseline** — clear build docs, contributing path, and tagged releases
- **Cloud sync polish** — self-host Docker path, launcher restore/conflict UX, more games covered via Ludusavi-backed paths
- **Installer reliability** — Windows setup + portable zip from CI when CEF packaging is stable here
- **Compatibility notes** — honest docs for anti-cheat / unsupported titles

## Next

- Broader game attach coverage and fewer sharp edges on first-run
- Richer built-in apps without bloating the core host
- Community app examples and a small “hello overlay app” template
- Optional signed releases

## Later

- Hosted app discovery (marketplace) — not required for the baseline
- Deeper multi-device sync strategies beyond last-writer-wins
- Non-Windows platforms — not on the critical path today

## Ideas welcome

Open an issue if something should move up. Please keep feature requests concrete (game + GPU API + what broke or what you want).
